# Eventicool

Eventicool is a platform for building beautiful event websites in minutes: clients
upload their pictures, pick a template, preview their site, then publish and share.

Stack: Vite + React + TypeScript + Tailwind CSS v4, Firebase, hosted on Netlify.

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
```
